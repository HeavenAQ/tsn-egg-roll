# Shopify Links Template

This branch is a minimal Shopify Online Store 2.0 theme template for a links page.

## Included

- `layout/theme.liquid`
- `config/settings_schema.json`
- `sections/main-links.liquid`
- `templates/page.links.json`
- `templates/index.json`
- `templates/page.json`
- `assets/theme.css`
- `locales/en.default.json`
- `locales/ja.json`

## Usage

1. Upload this theme to Shopify.
2. Create a page and assign the `page.links` template.
3. Customize links and texts in the Theme Editor.
